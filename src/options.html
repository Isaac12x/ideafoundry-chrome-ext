02   Remote requests

The on-page capture widget and remote requests only run on URLs listed below.

Use the IdeaFoundry app (<app address>/api/v1/capture) or a standalone queue (e.g. http://localhost:4318).

For the IdeaFoundry app, create the token under Settings → API keys. A standalone queue uses its own QUEUE_TOKEN.

Use https://chatgpt.com for the site root, an exact URL such as https://chatgpt.com/c/123 for one page, or https://chatgpt.com/* for non-root pages (this excludes the site root). Remote requests are checked about every 30 seconds. HTTPS is required for services outside localhost.
